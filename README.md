# 数当てゲーム（guess_game.py）

1〜Nの数字を当てるシンプルなCLIゲームです。難易度によって数字の範囲が変わります。

## 必要環境

- Python 3.10以上
- 外部ライブラリは不要（標準ライブラリのみ使用）

## 遊び方

```bash
python3 guess_game.py
```

起動すると難易度の一覧が表示されるので、番号（1〜3）を入力して選んでください。あとは範囲内の数字を入力して、正解を目指します。途中で終了したい場合は Ctrl+D（EOF）を入力してください。

## 難易度

| 番号 | 難易度 | 範囲 |
| --- | --- | --- |
| 1 | イージー | 1〜50 |
| 2 | ノーマル | 1〜100 |
| 3 | ハード | 1〜500 |

## 機能

- **距離に応じたヒント**: 予想が外れると「もっと大きい数字です。」または「もっと小さい数字です。」に加えて、答えとの距離に応じたヒントを表示します。
  - 差が5以内: 「あと少し！」
  - 差が20以内: 「近づいています。」
  - それ以上: 「まだ遠いです。」
- **ベストスコアの保存**: 正解時の試行回数をスコアとして、難易度別のベストスコア（最小回数）を `high_scores.json` に自動保存します。次回以降も記録が保持され、新記録を出すと「新記録です！」と表示されます。
- **入力バリデーション**: 数字以外の入力や範囲外の数字はエラーメッセージを表示して再入力を求め、試行回数にはカウントされません。
- スコアファイルの読み込み・保存に失敗した場合は警告を表示してゲームを続行します。
